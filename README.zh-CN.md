# GROUNDTRUTH

**证据优先的开源情报。** GROUNDTRUTH 是 [World Monitor](https://github.com/koala73/worldmonitor) 的一个分支，围绕一条原则重建：**零编造，零臆测**。

每条声明都带有声明等级（`OFFICIAL` / `JOURNALISTIC` / `ALLEGATION` / `SENSOR` / `VERIFIED_RECORD`）与可追溯的来源引用（规范 URL、发布者、检索时间戳、载荷 SHA-256）。无来源的记录会被拒绝；相关性永远不会被表述为归因或证据。

完整文档（英文）见 [README.md](./README.md)。许可证：AGPL-3.0-only。修改记录见 [MODIFICATIONS.md](./MODIFICATIONS.md)。
