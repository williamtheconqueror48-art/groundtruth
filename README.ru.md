# GROUNDTRUTH

**Разведка с приоритетом доказательств и открытым исходным кодом.** GROUNDTRUTH — форк [World Monitor](https://github.com/koala73/worldmonitor), перестроенный вокруг одного принципа: **ноль фабрикаций, ноль спекуляций**.

Каждое утверждение имеет уровень (`OFFICIAL` / `JOURNALISTIC` / `ALLEGATION` / `SENSOR` / `VERIFIED_RECORD`) и прослеживаемую ссылку на источник (канонический URL, издатель, время получения, SHA-256 полезной нагрузки). Записи без источников отклоняются; корреляция никогда не подаётся как атрибуция или доказательство.

Полная документация (на английском) — в [README.md](./README.md). Лицензия: AGPL-3.0-only. Список изменений — в [MODIFICATIONS.md](./MODIFICATIONS.md)。
