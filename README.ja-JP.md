# GROUNDTRUTH

**証拠優先のオープンソース・インテリジェンス。** GROUNDTRUTH は [World Monitor](https://github.com/koala73/worldmonitor) のフォークであり、「**捏造ゼロ、憶測ゼロ**」の原則のもとに再構築されています。

すべての主張にはクレーム等級（`OFFICIAL` / `JOURNALISTIC` / `ALLEGATION` / `SENSOR` / `VERIFIED_RECORD`）と追跡可能な出典参照（正規 URL、発行者、取得タイムスタンプ、ペイロードの SHA-256）が付与されます。出典のないレコードは拒否されます。相関を帰属や証拠として提示することはありません。

完全なドキュメント（英語）は [README.md](./README.md) を参照。ライセンス: AGPL-3.0-only。変更履歴は [MODIFICATIONS.md](./MODIFICATIONS.md)。
